# Білім Майданы — 3D білім сайысы

Екі оқушыға арналған 3D викторина-жекпе-жек (Three.js). Дұрыс жауап — қарсыласқа сиқырлы соққы.

- Екі ойыншы бір экранда: 1-ойыншы `1 2 3 4`, 2-ойыншы `7 8 9 0` немесе тінтуір.
- Дұрыс жауап: −20 HP, қатарынан 3 дұрыс жауап (КОМБО): −25 HP.
- Раунд саны, уақыт және сұрақтар мәзірде өзгертіледі (`Сұрақ | Дұрыс | Қате | Қате | Қате`).

```bash
npm install
npm run dev      # әзірлеу
npm run build    # dist/index.html — бүкіл ойын бір файлда, интернетсіз ашылады
```
